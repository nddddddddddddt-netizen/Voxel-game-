# Blockhaven (بلوك هافن) — 3D Native Voxel Game for Android

لعبة Voxel ثلاثية الأبعاد أصلية للأندرويد بمنظور الشخص الأول مع أصول أصلية 100%، توليد عوالم شبه لا نهائية، إضاءة ديناميكية، فيزياء واقعية، نظام مودات ثنائي المستويات (Level 1 Safe WASM Sandbox + Level 2 Power Mode)، وسيرفر متعدد اللاعبين.

---

## 🎮 الميزات الأساسية
- **محرك Voxel 3D أصلي**: مبني بـ OpenGL ES 3.0 عالي الأداء مع Shaders مخصصة، Greedy Meshing، وتظليل Voxel Ambient Occlusion (AO).
- **أصول أصلية 100%**: 34+ تكستشر Voxel بيسكل آرت أصلي (بدون أي تشابه أو أصول خارجية)، بالإضافة إلى مولد أصوات تركيبي (Procedural Audio Synthesizer) يولد أصوات الخطوات، التعدين، التكسير، وقطع الموسيقى المحيطية الهادئة.
- **توليد العالم الإجرائي**:
  - Chunks ثلاثية الأبعاد (16×16×128).
  - بذور عشوائية أو مخصصة (Deterministic Seeds) تعطي نفس العالم دائماً.
  - 6 بايومات متنوعة: السهول (Plains)، الغابات الكثيفة (Forest)، الكثبان الصحراوية (Desert)، الجبال الجليدية (Snowy Mountains)، المستنقعات (Swamp)، والجزر الاستوائية (Islands).
  - كهوف ثلاثية الأبعاد (3D Perlin Noise)، بحيرات، وشلالات.
  - طبقات الخامات بالعمق: فحم، حديد، ذهب، ألماس، بالإضافة لخامات أسطورية أصلية: **Etherite** (مضيئة بنفسجية)، **Pyrite** (نارية)، و**Luminite** (بلورات مشعة في الكهوف).
- **أسلوب اللعب (Survival & Creative)**:
  - تعدين حسب متانة الكتل وصلابتها، وضع الكتل بدقة مع فحص التصادم.
  - جرد كامل (Hotbar مكون من 9 فتحات + 27 فتحة تخزين).
  - تصنيع شبكي (Crafting Grid 2x2 و 3x3) مع وصفات للأدوات والأسلحة والدروع.
  - أفران الصهر (Smelting) لتحويل الخامات إلى سبائك وطهي الطعام وصناعة الزجاج.
  - قلوب الصحة (Health)، الجوع (Hunger)، ضرر السقوط، وفقاعة الهواء تحت الماء.
- **كائنات أصلية وذكاء اصطناعي**:
  - حيوانات أليفة: الخنزير البري (Voxel Boar)، الغزال الرشيق (Voxel Deer)، والطيور (Voxel Bird).
  - وحوش ليلية: كائن الظل المتربص (Shadow Lurker) وعنكبوت الكهوف (Cave Crawler).
- **تحكم لمس مخصص (Landscape)**:
  - جويستيك عائم يسار الشاشة مع استجابة دقيقة.
  - سحب لليمين لتحريك الكاميرا (Swipe Look) مع حساسية قابلة للتعديل.
  - أزرار القفز، التسلل (Sneak)، التعدين، البناء، والجرد.
  - دعم الاهتزاز اللمسي (Haptic Feedback).
- **نظام المودات ثنائي المستويات**:
  - **Level 1 (آمن / WASM & QuickJS)**: ساندبوكس معزول لتسجيل الكتل والعناصر والوصفات والأوامر بدون أي خطر على الجهاز.
  - **Level 2 (وضع القوة للأندرويد)**: يتيح تشغيل مكتبات ARM64 الأصلية وكود DEX مع تحذير للمطورين وموافقة صريحة.
  - أداة CLI باسم `bh` داخل مجلد `cli/` لإنشاء وبناء وتوقيع المودات (`.bhmod`).
- **أونلاين وسيرفر متعدد اللاعبين**:
  - كود سيرفر مستقل جاهز للنشر (`server/server.js` + `server/Dockerfile`).
  - دعم الغرف بأكواد الدعوة ومزامنة اللاعبين وتعديلات الكتل (Delta Sync).

## 🚀 طريقة بناء وتثبيت APK و AAB
1. **عبر GitHub Actions تلقائياً**:
   - تم إنشاء ملف `.github/workflows/build-android.yml`.
   - بمجرد عمل `git push` إلى مستودعك، يقوم GitHub ببناء ملفات APK (Debug & Release) وملف AAB ويرفعها كـ Artifacts جاهزة للتحميل المباشر على هاتفك.
2. **عبر سطر الأوامر (في بيئة السحابة)**:
   ```bash
   ./gradlew assembleDebug      # لبناء ملف APK
   ./gradlew bundleRelease      # لبناء ملف AAB للنشر
   ```

   - [ ] هل دوران الكاميرا باللمس في النصف الأيمن سريع وبدون تأخير؟
   - [ ] هل أزرار التعدين والبناء والقفز تستجيب مع اللمس المتعدد (Multi-touch)؟
2. **العالم والرسوميات**:
   - [ ] هل يتولد العالم بشكل متناسق مع الأشجار والكهوف والتضاريس؟
   - [ ] هل تعمل دورة الليل والنهار مع انتقال ألوان السماء وحركة الغيوم؟
   - [ ] هل تبدو شفافية الماء والكتل الشفافة صحيحة وبدون تشويش؟
3. **التعدين والبناء**:
   - [ ] جرب تكسير كتل الخشب والحجر: هل تظهر جزيئات التكسير ويُضاف العنصر للجرد؟

   - [ ] جرب وضع الكتل في العالم: هل تثبت في موقعها مع فحص الاصطدام باللاعب؟
4. **الأصوات والموسيقى**:
